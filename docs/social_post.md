### LinkedIn Variant (Longer):

```text
Most engineers today use AI coding agents in private terminal windows. But during production incidents, keeping the AI's diagnostic reasoning locked in one person's shell creates an information silo.

For the Flip the Switch Hackathon (organized by WeMakeDevs & DevTools Academy, powered by Switch AI), I built SwitchOps.

SwitchOps brings autonomous AI agents directly into team chat channels (Mattermost/Slack) using Switch AI:
- Instant Bug Triage: Developers dictate or paste bug reports in #bug-triage.
- Severity & Root Cause: The agent analyzes stack traces and classifies issues from P0 (Critical Outage) to P3 (Cosmetic).
- Public Team Thread: Remediations and code snippets are posted right in the shared thread so everyone stays aligned.
- Voice-First with Wispr Flow: Spoke technical stack traces and prompts at 96 WPM with zero voice typos.

Repo & live demo screenshots: https://github.com/devprotim/switch-workflow
```
